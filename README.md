# Deutsch Mastery 🇩🇪 — Arabic-first German learning platform

موقع عملي لتعلم الألمانية، مبني على الفهرس الجديد الذي أرسله صاحب المشروع: **Deutsch_A1_B2_Detailed_Index(1).pdf** (16 صفحة).

**حالة المشروع: قيد التطوير**. ليس منهجاً نهائياً مكتمل التدقيق ولا تدريباً كافياً بمفرده لاجتياز Goethe-Zertifikat A1–B2.

## المحتوى التعليمي الحالي

- **168 مسودة درس تفاعلي مرتبطة بموضوعات الفهرس**: A1 = 56، A2 = 44، B1 = 35، B2 = 33.
- **22 موضوعاً من A1** تم إثراؤها بشرح خاص وأمثلة ومفردات وأسئلة أكثر: أول 12 موضوعاً للنطق وأول 10 للتواصل.
- **24 درس قواعد جديداً** في B1 وB2، منها Plusquamperfekt وPassiv وFutur II وKonjunktiv I/II، مع مفردات ونصوص وأسئلة أصلية.
- **31 وحدة تطبيقية إضافية** من العمل السابق في A1 وA2، فيها شروح بثلاث نقاط، قراءة، حوار، مفردات وتمارين. موجودة في \`practice.html\` و\`pack.html\`. ليست كلها متطابقة موضوعاً بموضوع مع الفهرس الجديد.
- **284 موضوعاً ما زال دون تدريب تفاعلي مستقل**؛ تظهر كموضوعات مخطط لها، ولا تُحتسب مكتملة.
- **96 وحدة تدريبية سابقة** محفوظة في \`legacy.html\` لأغراض الاستفادة والرجوع؛ ليست هي المقياس الأساسي لتغطية الفهرس الجديد.

التدريبات الحالية تمثل **مادة تعليمية أولية** حتى عندما تتضمن تمارين ناجحة. نصوص B1/B2 والمهام الإنتاجية تحتاج إلى مراجعة بشرية وتوسعة وتقييمات شاملة.

## النطق الألماني

زر الاستماع **لا يستخدم صوت المتصفح العربي أو الإنجليزي**. يعرض فقط ملفات MP3 مولدة من صوت ألماني محدد \`de-DE-KatjaNeural\` عبر \`assets/german-player.js\` و\`data/audio-index.js\`.

عندما لا يتوفر تسجيل لمقطع جديد يظهر زر غير نشط في الواجهة الأساسية؛ لن يتم استخدام قارئ صوت بلغة أخرى. لتوليد الملفات الجديدة يُستخدم الإجراء \`.github/workflows/german-audio.yml\` بالاعتماد على \`scripts/audio_manifest.mjs\`.

هذا **نطق ألماني اصطناعي** لا تسجيل بشري. لا يوجد بعد تقييم حقيقي لنطق المتعلم بالميكروفون.

## تجربة التعلم

- كل موضوع له رابط مباشر مثل \`course.html?topic=A1-02-01\`.
- يتوفر شرح بالعربية الفصحى، أمثلة ألمانية، مفردات، محادثة، قراءة وتمارين حسب ما أُلف بالفعل.
- الأسئلة متسلسلة وتقيّم **الإجابة الصحيحة من أول محاولة**؛ تعاد الأسئلة للمراجعة.
- تتيح لوحة المتعلم حفظ التقدم، والمراجعة المتباعدة، وتصدير واستيراد نسخة احتياطية.
- **حفظ التقدم محلي داخل المتصفح فقط**. لا توجد حسابات مستخدمين أو مزامنة عبر الأجهزة.

## التحقق من الجودة

\`\`\`sh
node --check assets/primary-study.js
node --check data/master-curriculum.js
node --check data/curated-primary-2026.js
node tests/check.mjs
\`\`\`

توجد كذلك فحوص GitHub Actions للبنية والمتصفح. نجاح الفحص التقني لا يضمن دقة كل جملة أو اكتمال المستوى، ولذلك لا يوجد ادعاء بنسبة اكتمال وهمية.

## التشغيل المحلي

افتح ملفات المستودع عبر خادم محلي حتى يعمل التخزين والروابط باستقرار:

\`\`\`sh
python -m http.server 8000
\`\`\`

ثم انتقل إلى \`http://localhost:8000/\`. يدعم العرض كذلك GitHub Pages مباشرة دون نظام بناء إضافي.
