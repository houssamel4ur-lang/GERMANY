# Deutsch Mastery · منصة تعلم الألمانية 🇩🇪

منصة عربية لتعلم الألمانية ذاتياً من **A1 إلى B2** بتصميم مستقل، وصفحات دروس بروابط مباشرة، وتمارين قصيرة ومراجعة للعبارات.

> **حالة المشروع:** إصدار تطويري قابل للتجربة، **ليس** منهجاً نهائياً أو إعداداً كافياً لاجتياز امتحانات Goethe-Zertifikat A1–B2 بمفرده.

## المحتوى الحالي

| المستوى | الوحدات | أمثلة على الموضوعات |
|---|---:|---|
| A1 | 24 | التعارف، الأسرة، أدوات التعريف، الأرقام، التسوق، الصحة |
| A2 | 24 | الماضي Perfekt، الرسائل الرسمية، العمل، السكن، السفر |
| B1 | 24 | الرأي والنقاش، النصوص الإخبارية، العرض، تفسير البيانات |
| B2 | 24 | الحجاج، السياسات العامة، التكنولوجيا، الاقتصاد، التحليل |
| **المجموع** | **96** | **768 مدخلاً لغوياً مترجماً** |

في كل وحدة: مقدمة، مفردات مترجمة، استماع، قاعدة لغوية، حوار قصير، نص قراءة، تمارين وتقييم.

ملاحظة جودة: النصوص ومهام الكتابة والاستماع بالأخص في B1/B2 تحتاج **مزيداً من التوسع والمراجعة اللغوية البشرية** قبل اعتبارها مادة شاملة للمستوى. لا تتساوى «وحدة موجودة» و«مستوى مكتمل».

## التشغيل

هذا مشروع ثابت باستخدام HTML + CSS + JavaScript، بدون بناء برمجي وبدون حسابات.

1. اضغط **Code → Download ZIP** من GitHub.
2. فك الضغط مع الاحتفاظ بهيكل المجلدات.
3. افتح `index.html` في متصفح Chrome أو Edge.
4. إذا قيّد المتصفح تشغيل التخزين المحلي مع `file://`، استخدم خادماً محلياً:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000/` في المتصفح.

يمكن استخدام VS Code Live Server أيضاً.

## خريطة الملفات

- `index.html`: الرئيسية واختيار المستوى.
- `lesson.html?id=a1-01`: رابط درس مستقل (يمكن تغيير المعرف).
- `dashboard.html`: التقدم، المؤقت، النسخ الاحتياطي.
- `review.html`: بطاقات المراجعة المتباعدة.
- `assessment.html`: اختبار كلمات قصير لكل مستوى (ليس اختبار CEFR معتمداً).
- `quality.html`: حدود الجودة.
- `assets/style.css`: التصميم.
- `assets/app.js`: منطق التفاعل.
- `data/lessons.js`: بيانات دروس المستويات الأربعة.
- `data/part1.js`, `data/part2.js`: ملفات تأليف المحتوى.
- `data/enrich1.js`, `data/enrich2.js`: توسعات القراءة والمحادثة.
- `tests/check.mjs`: فحص تلقائي لاكتمال الحقول وتفرّد المعرفات.
- `.github/workflows/quality.yml`: اختبارات جودة مع كل تحديث.

**ملاحظة صيانة:** في الوقت الحالي `data/lessons.js` ملف تجميعي مبني من الملفات الجزئية. عند تحرير المحتوى، يجب إعادة توليده لضمان تطابق التغييرات.

## كيف تعمل الميزات؟

- **الصوتيات:** Web Speech API في المتصفح بنطق `de-DE`. الصوت ليس مسجلاً بشرياً؛ يتغير حسب الأصوات الألمانية المثبتة على الجهاز. لا يوجد تقييم موثوق لنطق المستخدم.
- **التمارين:** اختيار، استماع وفهم، كتابة، ترتيب كلمات، تصحيح فوري؛ النتيجة تعكس إجابات المستخدم ولا تعتمد على أرقام وهمية.
- **حفظ التقدم:** `localStorage` في هذا المتصفح فقط. يُفضل استخدام زر تصدير JSON في لوحة التقدم بانتظام.
- **المراجعة المتباعدة:** جدول فواصل 1، 2، 4، 8 أيام، يتغير حسب تقييم الاستذكار.
- **الخصوصية:** لا توجد خدمة تخزين سحابية أو تسجيل دخول؛ البيانات محلية ولا تُزامن بين الأجهزة.

## فحص الجودة

```sh
node --check assets/app.js
node --check data/lessons.js
node tests/check.mjs
```

الاختبار البنيوي لا يُغني عن تجربة الموقع فعلياً في متصفح وعمل مراجعة لغوية بشرية للغة الألمانية.

## النشر

الموقع قابل للاستضافة على GitHub Pages أو Cloudflare Pages أو Netlify باعتباره موقعاً ثابتاً.
إعداد GitHub Pages: `Settings → Pages` ثم اختيار مصدر النشر المناسب. **إتاحة Pages لمستودع خاص وظهور الموقع علناً يعتمدان على خطة GitHub وإعدادات الحساب.** لم يُنشر الموقع علناً تلقائياً.

## مرجع المستوى التعليمي

بُني تقسيم الموضوعات على متطلبات CEFR: [مجلس أوروبا](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors) و[Goethe-Institut](https://www.goethe.de/en/m/spr/kur/stu.html). لا يمثل هذا المشروع اعتماداً أو شهادة صادرة عن أي منهما.

## ما يلزم لإصدار شامل فعلاً

توسعة عدد الساعات التعليمية الفعلية، حوارات أصلية متعددة الأدوار، نصوص أصيلة طويلة بمستوى B1/B2، أصوات بشرية مرخّصة، تمارين كتابة مصححة، تقييمات استماع ومحادثة موثوقة، واختبارات نهائية موزونة للمهارات الأربع مع مراجعة من مختصين.
